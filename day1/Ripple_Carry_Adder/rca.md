# Ripple Carry Adder (RCA)

## Task Overview

This task implements a 4-bit Ripple Carry Adder (RCA) using Verilog HDL and verifies its functionality through simulation.

A Ripple Carry Adder is constructed by cascading multiple Full Adders. The carry output from each stage becomes the carry input to the next stage, causing the carry to "ripple" through the adder.

## Objective
-Design a 4-bit Ripple Carry Adder using Verilog.
-Implement the adder using four Full Adder modules.
-Simulate and verify the functionality using Vivado.
-Analyze carry propagation through successive stages.

## Design Description
### Inputs
| Signal | Width  | Description    |
| ------ | ------ | -------------- |
| A      | 4 bits | First operand  |
| B      | 4 bits | Second operand |
| Cin    | 1 bit  | Carry input    |
### Outputs
| Signal | Width  | Description        |
| ------ | ------ | ------------------ |
| S      | 4 bits | Sum output         |
| Cout   | 1 bit  | Final carry output |

## Working Principle

The Ripple Carry Adder consists of four Full Adders connected in series.

1. The first Full Adder adds:
A[0] + B[0] + Cin

2. Its carry output (c1) becomes the carry input of the second Full Adder.
3. This process continues through all four stages.
4. The final carry generated by the fourth Full Adder becomes the overall carry output (Cout).

## RTL Structure

A[0], B[0], Cin
       │
       ▼
    Full Adder ── c1
       │
       ▼
    Full Adder ── c2
       │
       ▼
    Full Adder ── c3
       │
       ▼
    Full Adder ── Cout

Sum Outputs: S[0], S[1], S[2], S[3]

## Module Hierarchy

```text
Ripple Carry Adder
│
├── Full Adder FA1
├── Full Adder FA2
├── Full Adder FA3
└── Full Adder FA4
```
